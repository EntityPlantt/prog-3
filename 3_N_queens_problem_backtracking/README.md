# N Queens problem
> На колку начини може да се постават $n$ кралици на $n\times n$ шаховска табла така што ни едни две кралици не се напаѓаат?

Овде го разгледуваме brute-force рекурзивниот алгоритам со backtracking. Во `main.cpp` го има кодот за овој пристап, заедно со код за бенчмаркинг во `main` функцијата. `main` функцијата принта на стандарден излез време на извршување, решенија (max. 30) и колку пати се повикала рекурзивната функција `nQueens`.

## Како работи алгоритмот
Алгоритмот се состои од една функција која се повикува рекурзивно: `nQueens`. За упростување на објаснувањево ќе ја нарекувам $f(r, mat)$.
